========================================================================
Warehouse Inventory BST & AVL Tree Concept Visualizer (MCA DSA Activity)
========================================================================

How to Run:
1. Double-click "warehouse_tree_visualizer.html" to open it in any modern web browser
   (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari).
2. No internet server, Node.js, or installation is required! It runs 100% locally.

Features Included:
- Problem 19: Binary Search Tree (BST) Warehouse Inventory
  * One-click Demo A: Random Order Insertion (Balanced BST, Height = 3)
  * One-click Demo B: Sorted Order Insertion (Degenerate Skewed Tree, Height = 7)
  * Interactive Insertion, Step-by-Step Search (Existing & Nonexistent IDs)
  * Inorder Predecessor & Successor Searching
  * Discontinued Record Deletion (Leaf, 1-Child, and 2-Children cases)
  * Ascending Inorder Sorted Product Catalogue
- Section K: Self-Balancing AVL Tree Rotations
  * Case 1: LL Rotation (Single Right Rotation)
  * Case 2: RR Rotation (Single Left Rotation)
  * Case 3: LR Rotation (Double Left-Right Rotation)
  * Case 4: RL Rotation (Double Right-Left Rotation)
  * Solve Skewed Warehouse Inventory: Automatic RR rotations keeping height = 3
  * Live Balance Factor (BF = Left Height - Right Height) tracking on every node
